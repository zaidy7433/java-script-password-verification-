# 🔐 JavaScript Password Verification

A simple Password Verification project developed using **HTML, CSS, and JavaScript**. This project checks whether the user's entered password matches the correct password using JavaScript conditional statements.

## 🌐 Live Demo
[Click Here to View Project](https://zaidy7433.github.io/java-script-password-verification-/)

## ✨ Features
- Takes password input from the user.
- Checks password correctness.
- Displays success or error messages.
- Uses JavaScript conditional statements.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📚 What I Learned
- JavaScript variables.
- `prompt()` function.
- `alert()` function.
- `if/else` statements.
- Comparison operators (`==`, `===`, `!=`).
